{%- comment -%} Shared filter behaviour for /research/publications/ and /research/presentations/. Operates on: .tag-filter the filter bar .tag-filter-btn[data-tag] topic/category toggles .tag-filter-reset one or more reset buttons .filterable[data-tags] the items to show/hide .filter-group[data-group] optional grouping wrappers (year groups) .filter-empty optional empty-state message Behaviour: starts with every tag ON (all items shown). Clicking a tag while all are on isolates it (others switch off). Further clicks toggle tags in an OR fashion. Emptying the selection, or pressing reset, returns to all-on. Items fade via CSS; empty groups collapse. {%- endcomment -%}
